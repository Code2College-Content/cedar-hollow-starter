# Cedar Hollow Coffee Roasters storefront (team repo)

Fictional business, made for practice in the Code2College Development Program.
This repo is public. Never put personal info here: no real names of customers,
no phone numbers, no passwords, no real client data.

## Who owns what

| Piece | Files | Owner |
|---|---|---|
| Products page | products.html, products.css | |
| Pickup order page | order.html, order.css | |
| About and Find us | about.html, about.css, listing-draft.md, captions.md | |
| Shared (whole team agrees first) | index.html, site.css, .github/copilot-instructions.md, header and footer | team |

## The three shared repo rules

1. One person per file. Only the owner edits their files.
2. Sync before you start. Commit and sync when you stop.
3. If you see the word "conflict", or a red error after Sync, stop and call the facilitator. Do not try to fix it alone.

## The facts

The six products and prices are in data/products.csv. Pickup days and places are on Marisol's card.
Never invent a price, a product, a pickup time or a delivery option.
